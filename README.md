# HUB-Core - PatchVehicleLimit

ASI plugin toi gian cho GTA San Andreas Multiplayer, chi giu lai ban va gioi han
vehicle tu `611` len `8000`.

Plugin chi cho phep ket noi den `127.0.0.1` hoac `26.42.80.113`.

## Build

```powershell
msbuild PatchVehicleLimit.sln /m /p:Configuration=Release /p:Platform=x86
```

File dau ra: `dist/HUB-Core.asi`.

Sau khi build Release, file cung duoc copy tu dong den `D:\GTA\HUB-Core.asi`.
